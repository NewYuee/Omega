# Omega Skills（第一版）

Skill 保存可复用的工作流程；项目状态和群组档案保存的是事实、决策与历史。Omega 不会把任何单条回复自动视作完整 Skill。

在主界面打开 **Skills**。单会话请选择连续的 1–8 个已完成问答轮次（可加载更早轮次）；群组请选择一个已归档的完整问题。先点「预览实际来源」，检查纳入的原文、轮次和未纳入的附件或工具条目。来源文字超过 60,000 字时不会静默截断，请缩小范围。附件内容目前不参与提炼；有遗漏时须人工补核。

点击「让会话整理草稿」后，Omega 在独立的只读提炼会话中生成草稿。生成可能持续数分钟，关闭窗口不取消任务；服务重启后未完成的提炼标记为失败，不会盲目重试。草稿区分适用条件、输入、步骤、验证方法和限制。请核对是否把中途试错当成最终流程、是否把未经验证的结果写成事实，以及是否含一次性路径或敏感数据。只有手动「确认并启用」后才能使用。

启用的 Skill 可以在任一单会话中点击「用于当前会话下一条消息」。输入框会显示一次性标记；发送成功后清除。Skill 仅作为本轮工作参考，不扩大目录、工具、审批或群组授权。草稿、启用、停用和修改均保留版本；来源轮次 ID 与提炼用的文字快照保存在本地 `omega.sqlite`，随普通备份保存，请勿公开分享备份。

第一版不自动推荐或全局注入 Skill；群组问题可作为提炼来源，但群组派发时直接选用 Skill 留待后续。自动提炼无法保证“方法正确”，需在实际任务中验证并修订。
