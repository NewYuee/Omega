# Omega v0.2 — 稳定日用版

版本目标：让 Omega 从功能原型进入可以长期挂在个人服务器、多设备反复连接、长会话与群组持续使用的稳定版本。

## 本版完成范围

- 统一版本号为 `0.2.0`，补齐本地启动、后台运行、Web、Electron 和 Android 的完整操作手册；Tauri 仅保留为移动端容器，桌面统一使用 Electron。
- HTTP/RPC 认证、设备标识、超时和错误解析收敛到独立 transport，减少聊天控制器继续承担协议细节。
- 群组成员任务记录持久化截止时间。Omega 重启后会使用原 `threadId + turnId` 自动核对已有执行轮次；完成的结果自动回收到群聊并继续队列，不创建第二轮任务。
- 原轮次明确中断、过期或找不到时保持暂停并提示人工重试，继续坚持“结果未知时不自动重放写操作”。
- 建立长群聊窗口的 DOM、JS heap 和重绘耗时预算，提供独立 Chromium 压力回归命令。

## 日用发布门槛

```sh
npm ci
npm run typecheck
npm test
npm run web:build
```

本机服务运行时追加：

```sh
npm run test:performance
```

多端安装包还必须在对应目标系统实机验证；构建成功不视为 Windows、macOS 或 Android 已通过日用验收。

## 保留边界

- 协调者正在生成计划或收尾时若服务重启，目前仍会暂停，因为任务尚无可安全对应的持久化执行记录。
- 任务轮次已明确进入 `interrupted` 时不会伪装完成，也不会自动重发；用户可检查成员会话后手动重试。
- v0.2 不承诺离线发送或跨设备同步未发送草稿。
- 桌面和 Android 正式公开分发仍需要用户自己的签名证书。

## 下一版候选

- 将 SSE 连接状态、历史控制和附件上传继续迁入严格类型的 React 状态层。
- 为协调者计划轮次增加与成员任务相同的持久化恢复记录。
- 增加 Windows 与 Android CI/实机矩阵、崩溃报告和可控的自动更新通道。
- 增加状态数据迁移版本、备份定期任务以及恢复演练报告。
