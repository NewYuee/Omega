# Omega v0.2.3

## 飞书图文与引用

- 支持直接发送图片与文字混排提问，保留图文顺序，并支持同时引用其他消息。
- 支持富文本及可读取的卡片引用，修复任务摘要遗漏原始引用资料的问题。
- 图文与引用共用附件限额、持久化恢复及权限校验；不支持的消息明确提示。
- 修复绑定移除持久化，提示多个飞书聊天复用目标时共享上下文。

## 仓库变更

- 可选择会话目录下的直属项目仓库，有界扫描并校验路径。
- 长文件路径自动换行，差异采用新增／删除高亮及原／新行号。
- 区分无仓库、Git 不可用、超时及输出超限；引用变更携带仓库路径。

## 升级说明

- 升级后重启 Omega 并刷新客户端。
- 不新增执行权限或多租户隔离；飞书授权不构成文件系统沙箱。
- 本版不包含后续开发中的项目状态记录。

所有平台安装包构建成功后统一附加并发布。
