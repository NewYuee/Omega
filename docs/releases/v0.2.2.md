# Omega v0.2.2

## 新增

- 飞书机器人接入：可视化配置、加密保存凭据、一次性配对、群聊和私聊绑定。
- 指定飞书群可选择允许所有成员使用，保留 @触发、原提问者操作权限和执行审批。
- 支持引用文本、图片、文本文件及 PDF／Office 文档，支持有界多层引用。
- 飞书结果采用 Markdown 卡片，优先更新原处理卡，长回复按编号分段；支持群组决策表单和停止任务。

## 修复与改进

- 群组历史进度不再持续显示“正在处理”，仅当前运行任务的最新消息显示实时状态。
- 引用附件实际传递给模型；备份包含文本附件，增加引用链与附件安全检查。
- 更新 Electron 和打包依赖，修复此前审计发现的依赖漏洞。

## 使用说明

- 升级后重启 Omega，刷新客户端。飞书接入默认关闭，可在“工作控制中心 → 连接与插件 → 飞书机器人”配置。
- 全群开放仅对指定绑定生效，包含以后加入的成员；成员共享目标上下文并消耗模型额度。
- 飞书配置与凭据不进入普通数据备份。未知派发或回传结果不会自动重发，需在 Omega 核对。
- 详情见 [飞书接入说明](https://github.com/NewYuee/Omega/blob/v0.2.2/docs/feishu-connector.md)。

安装包将在所有平台构建成功后统一附加到 Release。
