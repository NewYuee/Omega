# Omega v0.2.5

## 移动端工作入口

- 移动端将“项目”“待处理”和“变更”收入会话与群组的更多菜单，减少标题栏拥挤。
- 空白新会话仍保留工作入口，不再因没有历史问答而无法打开工作面板。
- 工作面板通过 React 状态动作统一打开，避免跨组件模拟点击。

## 原生客户端

- 原生客户端支持经过校验的多级 API 路径，修复飞书通知群组和成员接口无法访问的问题。
- 继续拒绝跨服务器、路径跳转、空路径段及非法字符。

## 升级说明

- 升级后重启 Omega 并刷新客户端。
- 本版不扩大飞书授权范围，也不改变现有执行审批与文件系统边界。
- Android、macOS 和 Windows 安装包构建成功后由发布流程统一附加到 Release。
