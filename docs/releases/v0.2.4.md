# Omega v0.2.4

## 项目状态与连续记忆

- 新增独立于会话的项目状态面板，记录现状、决策、待办、阻塞和验证证据，并保留来源与修订历史。
- 关联单会话的最终回复和群组主持人的最终总结可自动形成待确认候选；重复来源不会反复生成。
- 已确认记录和少量明确标注的自动候选可进入后续上下文，未确认内容不会冒充事实、测试结果或执行授权。

## 会话体验

- 单会话历史支持向上动态加载，并缓存最近访问会话的内容与滚动位置。
- 会话列表显示执行状态，侧栏支持拖动调整宽度；代码块复制在浏览器与桌面端统一处理。
- 输入框新增受保护的斜杠命令标识，图片、文件、成员提及与命令保持一致的编辑体验。

## 飞书通知

- 可从个人／群组输入框或消息操作中打开飞书通知，选择已绑定群及群成员，发送原生 @ 文本或 Card 2.0 卡片。
- 群与成员使用稳定 `chat_id`、`open_id` 校验，发送前重新确认成员仍属于目标群。
- 修复只引用消息并 @ 机器人时无正文不触发处理的问题，并补充所需飞书权限说明。

## 系统与升级

- 工作控制中心新增 Codex 账户、额度及用量展示；不可用字段保持明确降级。
- 升级后重启 Omega 并刷新客户端。项目自动候选不代表人工确认或实际测试成功。
- 安装包仅在新版本标签触发，并在 Android、macOS、Windows 产物全部成功后统一发布。
