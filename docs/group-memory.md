# 群组档案（第一版）

群组问题完成后，Omega 按问题保存一条档案。普通协作由协调者在成员交付后提炼摘要和未完成事项；讨论模式直接归档主持人的最终报告。摘要是自动整理的线索，不等于用户确认、测试通过或执行授权。

档案与聊天记录分开保存：原问题、交付、成员任务与完整结果、讨论报告和相关群组消息保留在档案详情中。后续派发只附带该群组最近及与当前问题相关的少量摘要（最多约 3600 字符），不会加载整份历史。跨群组不会共享档案；已有项目状态记录仍按原来的项目关联机制使用。

在群组左侧「群组摘要」中打开「查看群组档案」，可浏览历史问题、展开原始内容与修订记录、纠正摘要和待办，或标记为「已过时」。过时记录仍可查，但不再注入后续会话。保存使用版本号检测冲突；若他人已修改，刷新后再编辑。

注意：自动归档失败时，交付不会回滚；档案会标为待整理并保留原始内容。归档不是全局知识检索，也不自动验证成员声称的测试结果。重要决策和验证结论仍应由用户核对来源，并沉淀到项目状态记录。
