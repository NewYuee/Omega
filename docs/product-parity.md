| 领域 | 当前状态 | 已有证据 | 后续工作 |
| --- | --- | --- | --- |

| 单聊 | 核心功能可用 | React 消息主体、历史分页、流式回复、工具结果、附件、模型、审批、停止、增量全文索引和未读计数 | 扩大旧历史的后台索引覆盖并增强消息引用体验 |

| TypeScript 服务端 | 核心迁移完成 | `server.ts`、群组 SQLite/调度、共享契约、官方协议绑定、Bridge、自动化、历史、附件、指标、模型设置和群组进度全部进入严格检查；Bridge 支持 App Server 异常退出后的指数退避重连 | 后续按领域继续收窄 SQLite 动态行类型；兼容 `.mjs` 仅转发，不含业务实现 |
| Electron 桌面端 | 核心外壳可用 | 安全 preload、加密连接资料、菜单、托盘、通知、快捷操作；macOS ARM 应用完成连接烟测 | 正式图标/签名、公证和 Windows 实机验证 |
| Web | 核心版可用 | React 双聊天主体与输入器、统一状态、全局搜索、系统健康、备份恢复；历史保持固定窗口，客户端具有稳定设备标识、带数量和位置的服务端未读账本及 SSE 游标续传；长群聊 Chromium 压力预算已自动化 | 补充不同手机真机的输入延迟、帧率和系统回收恢复基线 |

| 自动化 | 核心版可用 | SQLite 定时计划、已有会话执行、立即运行/暂停/删除及完成状态测试 | 增加错过任务策略、运行历史和通知偏好 |
| 插件与工具连接 | 实验版可用 | Apps/MCP 状态、App 启停、MCP OAuth/刷新、插件安装卸载确认 | Codex 插件协议稳定后锁定契约并补连接详情页 |
| 电脑/浏览器操作 | 路由版可用 | 可向指定上下文会话发送受审批约束的浏览器/电脑任务 | 按实际 MCP/执行器补截图时间线、人工接管；尚无内置 VNC |

“核心版可用”表示当前 Omega 已有真实后端闭环；“进行中”表示新技术栈迁移尚未完全替换旧模块；“待调查”表示缺少足够行为证据，不能声明完成。
